# MBG

Full-stack application project consisting of a Golang backend (MVC, Clean Code, SOLID, Swagger) and a React frontend (Vite, Tailwind CSS v4).

## Project Structure

- **[backend/](backend)**: Golang REST API server built with MVC architecture, Clean Code & SOLID principles, documented with Swagger UI.
- **[frontend/](frontend)**: React + Vite web client styled with Tailwind CSS v4.

## Quick Start

### Backend
```bash
cd backend
go run main.go
```
- Server: `http://localhost:8080`
- Swagger UI: `http://localhost:8080/swagger/index.html`

### Frontend
```bash
cd frontend
npm install
npm run dev
```
- Dev Client: `http://localhost:5173`
